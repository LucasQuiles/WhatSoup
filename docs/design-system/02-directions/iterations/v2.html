Annotations

Blend thesis — what this v2 locks

B remains the voice; A is the signature; C is the muscle. The editorial chassis (Geist pair, elevation law, electric blue spent exactingly, calm inbox) carries every screen. A’s instrument discipline shows up exactly twice — the engraved SOUP nameplate and the shape-coded status law — which is enough to make the product unmistakable without costing the calm. C supplies the operational muscle: two densities, one toolbar, a real log surface, and the drawer that makes drill-in contextual instead of navigational.

State taxonomy — locked candidates

  • Line status: online (disc) · degraded (diamond) · unreachable (square) · unlinked (outline). Shape + color + label, always.
  • Surface states: loading (skeleton mirroring geometry) · empty (remedy offered) · error (retry mandatory) · degraded (wash + edge + diamond).
  • Density: default and compressed only — a component property, never a per-screen override.

Self-critique resolution (from Round 0)

  • Vercel-adjacency → the nameplate is now the brand carrier: mono spaced-caps engraving with a teal tick reads instrument-grade, not Geist-school; the mode trio is present in the header strip, feed edges, pickers and wizard — chroma identity on every screen.
  • Single-state drill-in vignette → replaced by C’s drawer: open by default on “sales”, re-openable from any flagged row, carrying status, remedies and a scoped live log — a full treatment, in context.
  • Inline-style shortcut → tokens and classes do the work; the residual inline styles carry only var() references or data-driven custom properties (chart bar heights), which is the lintable rule the T6 spec will encode.

Typography & grid

Geist + Geist Mono kept from the chassis; offline the file degrades to Helvetica/Arial and the platform mono without breakage. Everything sits on the 4px grid: control heights 24/28/32, row heights 28/36, leadings 16/20/24/28/32. No purple gradients, no glass under data — elevation is luminance (dark) or shadow (light), full stop.

SOUP Design System v3 — v2 blend (G2 lock candidate). Self-contained HTML; fonts via Google Fonts with graceful fallback; renders offline. Data is the deterministic console mock set (fictional +1 555-01xx numbers).
