Annotations

Direction thesis

Restraint is the spectacle. Direction B bets that a single operator watching eight lines needs the interface to disappear: monochrome chrome 1–2 contrast notches below content, one electric accent spent only on actions, focus and “now”, and a quiet mono lane carrying every number at tabular width. Density comes from hierarchy and alignment — not compression, not decoration.

Against sibling directions: A-Instrument speaks louder per pixel (annunciator hardware); C-Ops packs more pixels per state (telemetry walls). B claims the middle that Linear and Geist proved viable: calm that survives a crisis, because warn/crit are the only loud things left on screen.

P1 register — consolidated answers shown above

P1-1 one Button, 6 variants × 3 sizes + one reveal-label action mechanic · P1-2 one Modal anatomy + stacking-aware useDismissable · P1-3 semantic tokens remapped per [data-theme] · P1-4 one status/mode map, shape+color+label renderers · P1-5 one Pill primitive (tone × size × behavior) · P1-6 three-tier token file, component constants scoped out of :root.

Token architecture preview

/* tier 1 — primitives: never consumed by components */
--blue-500: #6BA6FF;  --blue-600: #2563EB;
--gray-d-base: #0E1013;  --gray-l-base: #FAFAFA;

/* tier 2 — semantic roles, remapped per theme */
:root, [data-theme="dark"] {
  --surface-raised: #15181D;   /* elevate = lighten  */
  --shadow-raised:  none;
  --accent: var(--blue-500); --accent-fg: #0A0E14;
  --border-subtle: rgba(255,255,255,.11);
}
[data-theme="light"] {
  --surface-raised: #FFFFFF;   /* elevate = shadow   */
  --shadow-raised: 0 1px 2px rgba(16,18,22,.06),
                   0 2px 8px rgba(16,18,22,.05);
  --accent: var(--blue-600); --accent-fg: #FFFFFF;
  --border-subtle: rgba(16,18,22,.13);
}

/* tier 3 — component tokens, scoped, only on deviation */
.kpi { --kpi-value-size: 22px; }

/* derived channel scales — no hand-copied rgba */
--warn-wash: color-mix(in srgb,
             var(--warn-solid) var(--wash), transparent);

Theme switch is a token-set swap on <html data-theme> — zero component branches. This page’s own stylesheet is the demonstration: the toggle above rewrites one attribute.

Computed body-text contrast (WCAG 2.2 relative luminance, this file’s actual hexes):

PairDarkLight

All informative text ≥ 4.5:1 in both themes; --text-3 is formally classified incidental — placeholders and watermark labels, lint-banned as a sole information carrier. Status is never color-only: shape (circle / rotated square / square) + label always accompany the hue, and the warn/crit channels remain separable under deuteranopia because position and shape carry the signal. Focus rings are 2px + 2px offset, ≥ 3:1 in both themes (SC 1.4.11). Dialogs trap focus, restore it on close, and close one layer per Escape.

Typography & grid

Geist + Geist Mono (OFL, Google Fonts) — the natural fit for this direction’s Vercel/Linear lineage: a refined grotesk with engineering-drawing neutrality, and a mono whose tabular figures make eight-line scan columns read as one machined block. Offline, the file degrades to Helvetica/Arial and the platform mono without layout breakage; the ramp is metric-tolerant.

Everything sits on the 4px grid: control heights 24/28/32, leadings 16/20/24/28/32, paddings in --sp steps. No half-steps survive — where v2 needed 3/6/10px, the new ramp re-quantizes to 4/8/12. No purple gradients, no glassmorphism, no blur materials: elevation is luminance (dark) or shadow (light), full stop.
