SOUP Design System v3 — direction candidates

Three competing visual systems for the console reskin. Each file is self-contained; each has a dark ⇄ light theme toggle in its header. Review all three, in both themes, before G1.

A — Instrument

Hardware-panel precision: hairline rules carry structure, mono spaced-caps faceplate labels, gauge-rail KPIs, lamp indicators, one rationed signal-orange accent.
IBM Plex Mono + Plex Sans · accent #ff6b2b / #bc3d08 · densest hairline structure

B — Editorial Precision

Linear/Geist-school calm: structure felt not seen, chrome recedes below content, soft single-source elevation, exact focus rings, one electric-blue accent.
Geist + Geist Mono · accent #6BA6FF / #2563EB · "soup." lowercase wordmark

C — Ops Console, Refined

Distilled observability density: rigorously achromatic chrome — the only color is mode/status semantics; tabular rhythm everywhere; toolbar + log-stream as first-class patterns; two table densities.
Plex Sans Condensed + Plex Sans + Plex Mono · no accent color · SOUP rack-label lozenge

How to review: open each direction, toggle both themes, walk the four sections (control sheet → fleet dashboard → inbox → overlay), and read the annotations section at the bottom of each (token preview, naming vocabulary, motion budget, accessibility notes).

What G1 decides: direction or blend · naming vocabulary (all three independently propose Soup Kitchen → Fleet, noun Line) · required changes before refinement · anything missing. Critiques and scorecards: decision-log.md.
