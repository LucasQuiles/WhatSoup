Annotations

thesis · tokens · vocabulary · motion · accessibility

Direction thesis

The bet: density is a discipline, not a quantity. Direction C takes the Grafana/Datadog lineage and removes everything those tools tolerate — decorative chrome color, panel-in-panel nesting, three competing control styles — until only the operational signal is left. Chrome is rigorously achromatic in both themes; every chromatic pixel is a mode or status semantic. That makes the six-channel system (passive/chat/agent × ok/warn/crit) the entire visual identity: a healthy fleet is a quiet gray instrument with teal/cyan/violet identity ticks, and one degraded line is unmissable because nothing else competes.

Hierarchy is carried by weight, size, and alpha on a strict column grid — never by boxes-in-boxes. Tables, the log stream, the feed, and KPI cells all share the same tabular rhythm, so the eye learns one scanning gait for the whole console. There is exactly one toolbar pattern, one table (two densities), one modal anatomy, one pill: the DRUIDS singularity rule, scaled to a 4-page product.

The danger of this direction is clutter; the defense is ruthless alignment (4px grid, fixed column lanes, mono for every numeric/id/timestamp) and the annunciator law (status ink only in position-stable slots: dot column, left row-edge, KPI value, level tag).

Token architecture preview primitive → semantic → component · [data-theme] swap · zero component branches

/* 1 · PRIMITIVES — raw scales. Components never reference these. */
:root {
  --p-ink-2: #101316;  --p-teal-d: #2fd6ab;  --p-teal-l: #047a5b;  /* … */
}

/* 2 · SEMANTIC — one vocabulary, two hand-designed value sets. */
html[data-theme="dark"] {
  --surface-raised: var(--p-ink-2);          /* elevation = lighter   */
  --border-subtle:  rgba(255,255,255,.09);   /* white-alpha hairline  */
  --mode-passive:   var(--p-teal-d);
  --status-warn-wash: rgba(240,163,46,.10);
  --action-primary-bg: #e8eaed;              /* action ≠ status (P2-12) */
}
html[data-theme="light"] {
  --surface-raised: #ffffff;                 /* elevation = shadow    */
  --border-subtle:  rgba(16,19,22,.13);     /* black-alpha, STRONGER */
  --mode-passive:   var(--p-teal-l);         /* darker + saturated    */
  --status-warn-wash: rgba(151,88,10,.09);
  --action-primary-bg: #16191d;
}

/* 3 · COMPONENT — scoped deviations only (--c-*), never global. */
.btn   { --c-btn-h: 32px; height: var(--c-btn-h); }
.modal { --c-modal-w: 520px; width: min(var(--c-modal-w), 100% - 48px); }

/* Theme switch = attribute swap. No component knows which theme it is in. */

Budget: ~70 semantic tokens (6 channels × 4 strengths × 2 themes = 48, plus surfaces/text/borders/focus/motion). Lint: components may consume only --surface/--text/--border/--status/--mode/--action/--focus/--sp/--r/--dur/--ease; raw hex or --p-* in a component is an error. Single-consumer dimensions stay component-scoped (--c-*), fixing the 60-constant global pollution (P1-6).

Motion budget + reduced motion mechanical calm · the table IS the budget

Rule table: operator-caused state changes (tab, filter pill, sort, density, theme content) switch at --dur-instant (0ms). Spatial changes are brief, anchored, ease-out tweens: reveals and hover affordances at --dur-fast (120ms), overlays (modal rise 8px, toast rise 6px) at --dur-base (180ms), the drawer slide at --dur-slow (280ms). One easing: cubic-bezier(0.22, 1, 0.36, 1). Ambient motion is exactly two loops — the ok-dot breathing ring and the skeleton shimmer — both subtle, both liveness signals, not decoration. Keyboard-driven actions never animate.

Reduced motion: a single @media (prefers-reduced-motion: reduce) block zeroes every transition/animation, kills the shimmer overlay, and disables smooth scrolling. Nothing in the system communicates only through motion, so the reduced experience loses nothing — the reveal-label action button, for instance, simply shows its label instantly on hover/focus. Anything animated outside the four tokens is a lint finding.

Accessibility notes computed live from the active stylesheet

Contrast (computed at load, WCAG 2.x relative luminance): computing…. Text-on-surface pairs pass AA by palette construction (Radix method): --text-primary and --text-secondary clear 4.5:1 on every surface in both themes; --text-ghost (~3.4–3.5:1) is formally restricted to incidental structure labels and is never the sole carrier of information. Status foregrounds (--status-*-fg) are tuned per theme to clear 4.5:1 on their wash backgrounds.

Never color-only: status = color + shape (ok ●, warn ◆, crit □) + word; log levels = color + bordered letter (E/W/I/D, debug additionally dash-bordered); modes = color + letter glyph (P/C/A) + word in default-density rows; the failed bubble pairs its red border with an E-tag and the sentence “Not sent”. Focus: achromatic 2px ring + 2px offset at text-primary contrast (≈14.9:1 dark / 15.6:1 light against base — far above the 3:1 non-text minimum), visible on every interactive specimen on this page via keyboard. Structure: ARIA roles on tabs/dialog/listbox/status, aria-pressed on every filter, aria-invalid + described-by on error fields, disabled-with-reason via title on conditional tabs. Minimum data text is 11px mono used only for secondary lanes; primary data sits at 12px+.
