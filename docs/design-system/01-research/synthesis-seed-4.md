## New material adopted
- **T6:** NN/g rules — max ~3 type-size tiers for hierarchy, very few dominant elements; icon+label beats
  icon-only (larger target + clearer meaning); 70–80ch line length; error motion allowed only as subtle
  directional cue paired with text/icon/proximity. Media Queries L5 pointer/hover awareness — no
  hover-dependent critical interactions; `any-pointer`/`any-hover` thinking; viewport meta + zoomability;
  breakpoints from layout stress, never device classes; CSS Color 4 OkLCh (re-confirms seed-3 ramp method).
- **T7:** Stylelint added alongside ESLint as CSS-policy precedent (custom rules, naming patterns,
  autofix, staged rollout). Storybook/Chromatic governance restated (stories as executable docs,
  explicit sign-off before merge) — implementation-program candidates.
- **Evaluation scorecard** (adopted as G3/implementation review rubric): visual polish 20, accessibility 20,
  workflow clarity 15, tokenizability 15, implementation feasibility 15, motion restraint 10, microcopy
  maturity 5; no pass below 3 in any essential category or below 4 in feasibility/accessibility/
  tokenizability. Note: tokenizability + feasibility + microcopy are what separate "portfolio-grade
  visuals" from "production-grade systems."
- **Motion technique matrix:** scroll-linked motion and 3D/WebGL confined to narrative/marketing surfaces;
  SOUP product rule restated — "one premium hero behavior per screen, two or three reusable
  microinteraction patterns system-wide, near-zero ornamental motion in data-dense surfaces."
